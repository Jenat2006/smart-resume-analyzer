# Smart Resume Analyzer and Job Recommendation System

## 📌 Project Overview

Smart Resume Analyzer is an AI-powered web application developed using Flask, NLP, and Machine Learning. It analyzes resumes, extracts technical skills, calculates a resume score, and recommends suitable jobs based on resume content.

---

## 🚀 Features

- Resume Upload (PDF/DOCX)
- Resume Text Extraction
- NLP Text Preprocessing
- Skill Extraction
- Resume Score (0–100)
- Resume Improvement Suggestions
- Job Recommendation
- Flask Web Interface
